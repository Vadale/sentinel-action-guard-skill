# Contributing

Start with the README route and the declared scope of sentinel-action-guard. Report a minimal
synthetic input, the expected result, actual result, host/version and relevant
error. Distinguish a missing capability from a failure of a supported operation.

Do not upload private project files, conversations, personal assessments,
credentials or confidential test evidence. Replace sensitive data with a small
fictional reproduction you may share. A proposed change should explain the
problem and retain required limitations, credits and terms. Structure checks do
not establish model judgment or customer usefulness.

Run `python -B tests/check_package.py` after editing links or packaging.
